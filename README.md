# Núcleo

Pantalla de las funciones de la red social. Los botones abren cada función; las funciones todavía no están implementadas.

## Colores

| Uso | Hex |
|---|---|
| Fondo de la pantalla | `#121212` |
| Texto principal | `#E0E0E0` |
| Texto secundario | `#A3A3A3` |
| Tarjetas | `#1E1E1E` |
| Botones | `#2A2A2A` |
| Botón al pasar el mouse | `#363636` |
| Bordes | `#333333` |

## Abrir la pantalla

```bash
javac -encoding UTF-8 -d out src/main/java/org/example/interfaz/*.java
java -cp out org.example.interfaz.RedSocialApp
```
